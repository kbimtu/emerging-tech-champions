# Innovate & Inspire

1. EXECUTIVE SUMMARY - What is i2OL
KB Institute (https://kb.institute) -> i2OL umbrella -> [IDSOL, IBCOL, IQCOL] -> ETO optional side event.
i2OL is the international KB Olympiad and is an international emerging technologies competition [span_0](start_span)[span_0](end_span). It is inspired by the 7 bridges problem [span_1](start_span)[span_1](end_span). The initiative is celebrating its 9th anniversary [span_2](start_span)[span_2](end_span). Each competition starting as protests [span_3](start_span)[span_3](end_span). i2OL is the acronym for IBCOL, IDSOL, IQCOL as between "i" & "OL" there are two letters. These three project-based competitions focus on entrepreneurship and have their own technical focus [span_4](start_span)[span_4](end_span):
 * IDSOL: International Data Science Olympiad is an annual global competition for the best high- and low-level practical applications of Data Science & Artificial Intelligence (DSAI).
 * IBCOL: International Blockchain Olympiad is an annual global competition for the best high- and low-level practical applications of Blockchain & Trust Technologies (BCTT).
 * IQCOL: International Quantum Computing Olympiad is an annual global competition for the best high- and low-level practical applications of Quantum Computing & Information Theory (QCIT).
ETO is an optional side event that is industry-focused - there will be a pitching station where they have potential in receiving funding opportunities. The competitions are aimed at High School & Post-Secondary (Associate, Undergraduate, & Graduate) participants [span_5](start_span)[span_5](end_span).
Project Phases: 01 i2OL Qualifier Fully Online, 02 ETO In-Person Side Quest only applicable for qualified projects, 03 i2OL Final Evaluation Fully Online.
Submission is on a rolling basis - Submit Now https://join.i2ol.org
Team size any number. Streams SS ISCED 2-3 Secondary Schooler Stream, PS ISCED 4-8 Post-Secondary Student Stream. Categories IDSOL INFRA/PROD, IBCOL ARC/DEV, IQCOL APP/EXP.

- **Ship faster**: describe what you want to build and Lovable handles the code.
- **Stay in sync**: every change made in Lovable is committed straight to this repository.
- **Full ownership**: this code is yours. Push to `main` on GitHub and your changes sync back into Lovable, ready for your next prompt.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
